# Srinivasa Heights

Sales website for **Srinivasa Heights**, 20 premium 3 BHK apartments in Aravinda Nagar, Kadapa, by J.K Constructions.

- West-facing homes: 1,750 sq ft
- East-facing homes: 1,675 sq ft
- Starting from ₹4,500 per sq ft
- Contact: 86861 17007 · 99452 79015 · 97011 92444

## Files

- `index.html`: the whole site (HTML, CSS and JavaScript in one file)
- `img/`: building photo, logo, floor plans and 3D views

## Updating

- **Mark a flat booked:** in `index.html`, search for `var SOLD =` and add the flat number, e.g. `['101','102','103','104']`.
- **Change phone numbers:** search for the number and replace every match.

It is a static site, so it can be hosted on Netlify, GitHub Pages or any web host.
